SMSMode Bridge sur un commerce d'exemple

Le problème

Chaque commande contient un numéro que personne n'utilise

  • Le numéro de téléphone est dans la commande, et il n'arrive jamais dans votre outil SMS.
  • Constituer une liste de contacts, c'est recopier les numéros à la main.
  • Une promotion part à tout le monde, qu'ils aient commandé hier ou il y a 1 an.
  • Les clients qui ne commandent plus sont repérés des mois plus tard, quand ils le sont.

Ce que fait l'application

Vos clients dans smsmode, déjà triés

  • Enregistré à chaque nouvelle commande

    Une fois la passerelle activée, chaque nouvelle commande HubRise et son client sont enregistrés dans votre compte smsmode. Il n'y a rien à exporter.

  • Jusqu'à 10 groupes de clients

    Créez un groupe pour chaque public à toucher, comme les nouveaux clients, les habitués, ou ceux qui n'ont pas commandé depuis un moment.

  • Des règles réglées au curseur

    Triez les clients selon le nombre de commandes, le total dépensé, les points de fidélité et les dates de leur première et de leur dernière commande, puis selon le mode de service de leur dernière commande et le code postal.

  • Le consentement SMS dans les règles

    Un groupe peut aussi être trié selon le consentement au marketing par SMS, tel que les clients l'ont donné en commandant.

  • Connecté par 1 clé API

    Créez une clé API dans smsmode, collez-la dans la passerelle et activez-la. Il n'y a rien à installer.

  • Des campagnes envoyées depuis smsmode

    Rédigez et envoyez vos SMS dans smsmode. Le menu de la passerelle y mène directement.

Comment ça marche

Connecté en 4 étapes

  1. Étape 1

    Définir vos groupes

    Nommez chaque groupe et fixez ses règles.

  2. Étape 2

    Ajouter votre clé API smsmode

    Vous la créez dans smsmode, parmi ses clés API.

  3. Étape 3

    Activer la passerelle

    Dès lors, chaque nouvelle commande et son client sont enregistrés dans smsmode.

  4. Étape 4

    Envoyer votre campagne

    Dans smsmode, choisissez un groupe et rédigez votre SMS.

Questions

Questions sur SMSMode Bridge

Faut-il un compte smsmode ?

Oui. La passerelle enregistre les clients dans votre propre compte smsmode, connecté par une clé API que vous créez dans smsmode. smsmode a ses propres offres, facturées par smsmode.

Quand la passerelle commence-t-elle à enregistrer les clients ?

Dès que vous l'activez. À partir de là, chaque nouvelle commande qui arrive dans HubRise est enregistrée dans smsmode avec son client.

Comment les clients sont-ils triés en groupes ?

Selon les règles que vous fixez pour chaque groupe : nombre de commandes, total dépensé, points de fidélité, dates de la première et de la dernière commande, mode de service de la dernière commande, code postal et consentement au marketing par SMS.

Quelle différence avec Brevo Bridge ?

Les 2 trient les clients avec les mêmes règles de groupe. Brevo Bridge remplit un compte Brevo, pour l'e-mail et le SMS, et peut ne garder que certains modes de service et canaux. SMSMode Bridge remplit un compte smsmode, pour le SMS.

Faut-il un compte HubRise pour utiliser SMSMode Bridge ?

Oui. SMSMode Bridge se connecte au compte HubRise de votre commerce, là où votre caisse et vos plateformes de livraison envoient déjà leurs commandes. HubRise a son propre abonnement, facturé par HubRise.
